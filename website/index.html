Gym-Anything-RT

Scaling Real-Time Environments for Vision-Language Agents

Pranjal Aggarwal · Sean Welleck
Carnegie Mellon University

Video games and physical devices keep changing while an agent thinks. Gym-Anything-RT builds real-time minigames to measure this, and controls their clock so the same task can be played live, slowed down, or paused.

Findings

Key Results

Frontier models fail mainly because they are too slow. Giving them more time recovers most of the gap, and letting them write code that acts on their behalf recovers part of it.

Real Time Is the Gap

Pass rates on the 100 real-time minigames and their non-real-time counterparts.

Speed Is the Bottleneck

Slowing the environment raises Astra's pass rate on the same real-time tasks from 9% to 57%, and pausing raises it to 75%.

Code Partially Compensates

When allowed to run code, Astra writes scripts that perceive and act between its own responses, raising its real-time pass rate from 9% to 31%.

The Method

How It Works

Coding agents build each minigame as a program, and our evaluation stack controls its clock.

01 · CREATE

Creator and Auditor Agents

A creator agent turns a seed puzzle into a real-time minigame program with an oracle solution that shows the task is solvable. Independent audit agents test it and send problems back until it passes.

02 · CONTROL TIME

Live, Slowed, or Paused

Our evaluation stack controls every clock in the minigame, so the same task can run at its natural speed, slowed down to give the agent more time, or paused between observation and action.

03 · VARY

Controlled Variants

Each minigame has a non-real-time counterpart, five difficulty levels, and two interaction modes. Review agents label the capabilities each configuration requires.

Live

The minigame runs at its natural speed while the model reasons.

Slowed (up to 64×)

Every clock in the minigame runs slower, while actions and screenshots stay real time.

Paused

The minigame advances through a short observation window, then freezes until the model acts.
